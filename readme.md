# AfriConnect Summit 2026

## Description
AfriConnect Summit 2026 est un site web réalisé dans le cadre du projet d'examen de L1.
Il présente une conférence technologique fictive réunissant des experts africains.

## Fonctionnalités

- Page d'accueil moderne
- Programme interactif sur 3 jours
- Filtrage dynamique des intervenants
- Formulaire de contact avec validation JavaScript
- Dark Mode
- Compteurs animés
- FAQ en CSS
- Design responsive (Mobile, Tablette, Desktop)

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git & GitHub
